03 / QUICK START

From Git to DAGs.

Add a sync companion to your existing Airflow stack.

Original Compose example ↗
01

Pull the image

Use the published Docker image from the project README. Docker with Compose is required.

bash 
docker pull enzzo657/airflow-git-sync:latest
02

Add the sync service

Merge this service into your Airflow Compose file. This adapts the repository example to read your settings from a local .env file.

The Docker socket mount lets the container restart other containers on the host. Mount ./repo into Airflow too, with DAG and plugin paths matching your repository layout.

docker-compose.yml 
services:
  airflow-git-sync:
    image: enzzo657/airflow-git-sync:latest
    container_name: airflow-git-sync
    environment:
      REPO_URL: ${REPO_URL:?Set REPO_URL}
      GIT_BRANCH: ${GIT_BRANCH:-master}
      SYNC_ROOT: /opt/sync
      AIRFLOW_RESTART_SERVICES: ${AIRFLOW_RESTART_SERVICES:?Set container names}
      SYNC_INTERVAL: 20
    volumes:
      - ./repo:/opt/sync
      - /var/run/docker.sock:/var/run/docker.sock
    healthcheck:
      test: ["CMD", "test", "-f", "/opt/sync/.git/HEAD"]
      interval: 5s
      timeout: 5s
      retries: 12
      start_period: 10s
    restart: unless-stopped
03

Set your environment

Create .env next to the Compose file. Replace the URL, branch, and container names with your values. AIRFLOW_RESTART_SERVICES uses space-separated Docker container names, not Compose service keys.

For a private repository, provide a URL with credentials as in the upstream example. Keep credentials out of version control.

.env 
REPO_URL=https://github.com/your-org/your-airflow-dags.git
GIT_BRANCH=main
AIRFLOW_RESTART_SERVICES=airflow-airflow-scheduler-1 airflow-airflow-worker-1
04

Wait for Git. Start Airflow.

Add this dependency to each Airflow service that reads the repository. Preserve its existing dependencies. The healthcheck waits for .git/HEAD; it does not validate DAGs. Then start the stack.

docker-compose.yml · Airflow 
depends_on:
  airflow-git-sync:
    condition: service_healthy
bash 
docker compose up -d
↳

Use a dedicated checkout: synchronization resets tracked files and removes untracked and ignored files, with Python cache exclusions in the script. Keep local work outside SYNC_ROOT.

04 / CONFIGURATION

Small config. Full control.

Four required values. One optional polling interval.

ENVIRONMENT
Environment variable reference
Variable Default Description
REPO_URL Default: Required Git repository URL. Must be accessible from the sync container.
SYNC_ROOT Default: Required Checkout directory inside the container. The Compose example uses /opt/sync, mounted from ./repo.
GIT_BRANCH Default: Required Remote branch to synchronize. The Compose example uses master; set your actual branch.
SYNC_INTERVAL Default: 10 Seconds to sleep after each sync completes. Optional; the Compose example sets 20 seconds.
AIRFLOW_RESTART_SERVICES Default: Required Space-separated Docker container names to restart when the plugins directory hash changes.
